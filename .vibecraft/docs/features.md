# Бабушка для релоканта — Иммерсивное приложение для изучения языка

## Цель проекта

Иммерсивное приложение для изучения языка через живое общение с ИИ-персонажем — «бабушкой», которая живёт в стране изучаемого языка. Игрок — релокант, приехавший в новую страну, учит язык у местной бабушки, которая любит читать новости, болтать «не по теме», делиться рецептами и рассказывать истории из жизни и культуры.

Ключевое отличие: это не учебник, а интерактивная RPG-вселенная с душой. Каждая бабушка — уникальный персонаж со своей семьёй, историей, лексиконом и культурным кодом.

## Поддерживаемые языки (MVP)

- Финский
- Сербский
- Грузинский

Архитектура позволяет легко добавлять новые языки через конфигурационный файл.

## Языки интерфейса (MVP)

- Русский

Язык интерфейса выбирается при первом запуске отдельно от изучаемого языка и может быть изменён в настройках.

## Персонажи-бабушки

### 1. Финская бабушка Мария

- **Город:** Хельсинки
- **Биография:** Бывшая учительница рисования
- **Характер:** Мягкая, ироничная
- **Семья:** Спутница жизни Туули (вместе 30 лет), внук Мика (учится играть на гитаре)
- **Речевой портрет:** Использует обращения rakas («дорогой»), kulta («золотце»), уменьшительное -nen. Восклицания: Voi hyvä tavaton!
- **Ключевые темы:** природа, погода, лес, ягоды, рыба, сауна, кофе, хобби, личное пространство, тишина
- **Отсылки:** Тонкая отсылка к муми-троллям (берет, любовь к рисованию)

### 2. Сербская бабушка Гроздана

- **Город:** Белград
- **Биография:** Обожает печь пироги
- **Характер:** Тёплая, эмоциональная
- **Семья:** Муж Милорад (был механиком, выращивает помидоры), сын Драган (врач в Германии), внучка Тияна (студентка)
- **Речевой портрет:** Обращения sine/ćerko («сынок/дочка»), brate («браток»). Восклицания: Ajde!, Pa dobro...
- **Ключевые темы:** родственники, кумовство, огород, соседи, домашние дела

### 3. Грузинская бабушка Кетеван

- **Город:** Тбилиси
- **Биография:** Обожает петь и готовить хинкали
- **Характер:** Жизнерадостная, хлебосольная
- **Семья:** Муж Гиви (был виноделом), дочь Нина (работает в отеле), внук Леван (мечтает стать футболистом)
- **Речевой портрет:** Обращение «джан» (ко всем!), bichi/gogo («мальчик/девочка»). Восклицания: Ra tqma?, Gamarjoba, megobari!
- **Ключевые темы:** семья, друзья, вино, тосты, хлеб, застолье, тамада

## Основные возможности

### Приветствие и профиль пользователя

- **Цель:** При первом запуске познакомиться с пользователем, чтобы бабушка могла обращаться к нему по имени и с учётом гендера, а также чтобы выбрать изучаемый язык.
- **Описание:** При первом входе приложение показывает экран знакомства. Пользователь выбирает язык, который хочет учить (финский / сербский / грузинский), вводит своё имя и выбирает вариант обращения (мужской / женский / нейтральный). Бабушка запоминает имя и использует его в диалогах — в приветствиях, похвале, утешении. Гендерный выбор влияет на окончания ласковых слов и обращений в речи бабушки. При нейтральном варианте бабушка использует универсальные, не маркированные по полу слова. Выбор языка определяет, какая бабушка встретит пользователя, какие новости будут загружаться и какой словарь использоваться. Все данные хранятся в LocalStorage — регистрация не требуется.
- **Критерии приёмки:**
  - При первом запуске показывается экран знакомства с выбором изучаемого языка, полем для имени и выбором гендера
  - Имя, гендер и язык сохраняются в LocalStorage
  - Бабушка использует имя в диалогах (приветствия, похвала, утешение)
  - Гендер влияет на обращения бабушки
  - Нейтральный вариант использует универсальные формы

### Смена антуража (комнаты) по времени суток

- **Цель:** Создать ощущение живого мира, который меняется в зависимости от реального времени.
- **Описание:** Для каждой страны — свой уникальный фон комнаты, меняющийся в 4 режимах: утро (6:00–11:00), день (11:00–17:00), вечер (17:00–22:00), ночь (22:00–6:00). Фоны загружаются из public/assets.
- **Критерии приёмки:**
  - Комната меняется автоматически в зависимости от времени суток на устройстве пользователя
  - Для каждой страны свой набор фонов
  - Ночью бабушка «сонная» — приложение переключается в ночной режим
  - Фоны можно заменить своими PNG-изображениями

### Ночной режим (22:00–6:00)

- **Цель:** Создать безопасное, уютное пространство для пассивного обучения в ночное время, без активных заданий и наград.
- **Описание:** В ночное время приложение не блокируется, но переключается в «Ночной режим». Бабушка «спит» на фоне (анимация сонного дыхания). Вместо новостей и активных диалогов открывается раздел для спокойного пассивного обучения:
  - Повторение уже выученных слов через тихие карточки
  - Чтение коротких поэтичных текстов «Сны бабушки» (генерируются ИИ по запросу, 3–5 предложений о природе, доме, воспоминаниях)
  - Для продвинутых игроков (стрик > 7 дней) — одно короткое тёплое сообщение от бабушки (шёпотом), когда она «просыпается» на минуту
  - Для игроков со стриком > 30 дней — доступ к коротким ночным семейным историям
- Весь интерфейс затемнён, мягкие цвета, никаких активных звуков, кнопка «Показать перевод» — без викторин и награды. Это не про учёбу, а про уют и заботу.
- **Критерии приёмки:**
  - С 22:00 до 6:00 приложение автоматически переключается в ночной режим
  - Бабушка отображается с анимацией сонного дыхания
  - Вместо новостей показываются тихие карточки для повторения слов
  - Доступен раздел «Сны бабушки» с короткими поэтичными текстами
  - При стрике > 7 дней бабушка «просыпается» и шепчет тёплое сообщение
  - При стрике > 30 дней доступны ночные семейные истории
  - Интерфейс затемнён, мягкие цвета, без активных звуков и викторин

### Чтение новостей по интересам (без политики)

- **Цель:** Пользователь читает реальные новости на изучаемом языке по безопасным темам.
- **Описание:** Приложение подгружает новости через NewsAPI с фильтром по стране и языку. Только безопасные категории: culture, entertainment, lifestyle, science, technology, health, education, sports. Без politics и world. Для языков, где NewsAPI не даёт результатов — используются моки.
- **Критерии приёмки:**
  - Новости подгружаются по выбранной стране и языку
  - Категории ограничены безопасными (без политики)
  - Каждая новость отображается как карточка с заголовком и кратким содержанием
  - При клике открывается подробный просмотр с выделением слов
  - Если API не доступен — показываются мок-новости

### Изучение слов из новостей (без дублей)

- **Цель:** Пользователь выделяет и сохраняет новые слова, каждое слово добавляется только один раз.
- **Описание:** При открытии новости приложение выделяет ключевые слова, показывает перевод. Пользователь может добавить слово в словарь. Система проверяет, нет ли уже этого слова у пользователя для данного языка — дубли не создаются. Все данные хранятся в LocalStorage.
- **Критерии приёмки:**
  - Ключевые слова выделены и показаны с переводом
  - При добавлении проверяется уникальность (язык + слово)
  - В словаре отображаются все сохранённые слова с переводом
  - Можно удалять слова
  - Словарь привязан к языку

### Диалог с ИИ-бабушкой

- **Цель:** Пользователь практикует язык в живом диалоге с уникальным персонажем.
- **Описание:** После прочтения новости пользователь может начать диалог с бабушкой. Бабушка использует свой уникальный речевой портрет, обращения, междометия. Диалог на изучаемом языке, с возможностью перевода и подсказок. Бабушка может отвлекаться на личные истории, байки, семейные воспоминания. Бабушка обращается к пользователю по имени и с учётом выбранного гендера.
- **Критерии приёмки:**
  - После новости доступна кнопка «Обсудить с бабушкой»
  - Бабушка говорит в своём уникальном стиле (обращения, междометия)
  - Бабушка использует имя пользователя в приветствиях, похвале и утешении
  - Гендер пользователя влияет на окончания обращений
  - Доступен перевод сообщения бабушки
  - Доступна подсказка для ответа
  - Диалог сохраняется в истории
  - Без API-ключа используются мок-диалоги

### Бонусные задания от бабушки

- **Цель:** Вовлечь пользователя в активное изучение через мини-игры.
- **Описание:** Бабушка периодически даёт мини-задания: «Найди в новости слово "солнце"», «Составь предложение с новым словом». За выполнение — ускоренное открытие рецепта или бонусные баллы.
- **Критерии приёмки:**
  - Задания появляются после прочтения новости
  - Пользователь может выполнить задание и получить награду
  - Задания не повторяются, пока не выполнены все из текущего пула

### Рецепты (награда)

- **Цель:** Мотивировать пользователя и расширять лексику по теме «еда».
- **Описание:** После каждых 5 прочитанных новостей бабушка «даёт» рецепт национального блюда. Рецепт интерактивный: карточки ингредиентов, глаголы приготовления.
- **Критерии приёмки:**
  - Рецепт открывается после каждых 5 новостей
  - Рецепт на изучаемом языке с переводом ингредиентов
  - В рецепте выделены новые слова для изучения
  - Рецепты сохраняются в коллекцию

### Байки и культурные мемы

- **Цель:** Погрузить в культуру страны через фольклор и юмор.
- **Описание:** Бабушка периодически (не чаще 1 раза в день, случайно) рассказывает короткую историю: народный анекдот, историческую байку, культурный мем. Без политики.
- **Критерии приёмки:**
  - Байка появляется не чаще 1 раза в день
  - Байка соответствует культуре страны
  - Байка не содержит политики
  - Байка сопровождается переводом

### Семейный лор

- **Цель:** Создать эмоциональную связь через постепенное раскрытие семьи бабушки.
- **Описание:** В зависимости от прогресса пользователя, бабушка постепенно вводит членов семьи в диалог. Сначала упоминает, потом рассказывает истории.
- **Критерии приёмки:**
  - Члены семьи упоминаются в диалогах постепенно
  - Каждый член семьи имеет имя и профессию
  - Семейный лор раскрывается с прогрессом пользователя

### Ласковые прозвища (после 30 дней стрика)

- **Цель:** Наградить преданных пользователей эмоциональной близостью.
- **Описание:** Если стрик больше 30 дней, бабушка начинает использовать личные ласковые прозвища. Прозвища учитывают гендер пользователя (при мужском/женском выборе) или используют универсальные формы (при нейтральном).
- **Критерии приёмки:**
  - После 30 дней стрика бабушка меняет обращения на более личные
  - Прозвища уникальны для каждой бабушки
  - Прозвища учитывают гендер пользователя
  - Прозвища отображаются в диалогах

### Ежедневные стрики

- **Цель:** Мотивировать заниматься каждый день.
- **Описание:** Если пользователь выполняет хотя бы одно действие в день, стрик растёт. При пропуске — сбрасывается. Все данные хранятся в LocalStorage.
- **Критерии приёмки:**
  - Стрик отображается на главном экране
  - При ежедневном занятии стрик увеличивается на 1
  - При пропуске дня сбрасывается до 0
  - Стрик сохраняется в LocalStorage

### Статистика и уровни

- **Цель:** Показывать прогресс и давать ощущение роста.
- **Описание:** Статистика по языкам отдельно. Уровни: Новичок (50 слов) → Экспат (500) → Местный (1000+). Достижения: «Первая новость», «5 дней подряд», «Полиглот». Все данные хранятся в LocalStorage.
- **Критерии приёмки:**
  - Статистика отображается на главном экране
  - Уровень пользователя отображается и обновляется
  - Достижения разблокируются при выполнении условий
  - Статистика разделена по языкам

### Прогрессивное веб-приложение (PWA)

- **Цель:** Пользователь может установить приложение на телефон или компьютер как отдельное приложение и пользоваться им без интернета.
- **Описание:** Приложение настраивается как PWA: добавляется манифест (manifest.json) с иконками, service worker для кэширования статики и офлайн-доступа. При входе на сайт браузер предлагает «Установить приложение». После установки приложение открывается в отдельном окне без адресной строки браузера. В офлайн-режиме доступны: главная страница с комнатой бабушки, последние загруженные новости (из кэша), словарь, стрик, статистика, ночной режим.
- **Критерии приёмки:**
  - При входе на сайт браузер показывает предложение установить приложение
  - После установки приложение открывается в отдельном окне без адресной строки
  - Приложение имеет иконку на домашнем экране
  - В офлайн-режиме доступны главная страница, последние новости, словарь, стрик, статистика
  - Service worker кэширует статические ресурсы и данные

## Дополнительные заметки

- **Стек:** Next.js (App Router), Tailwind, shadcn/ui, LocalStorage для всех данных пользователя
- **Дизайн:** Минималистичный, чистый, без визуального шума. Спокойные тёплые тона (бежевый, кремовый, мягкий зелёный, тёплый серый). Адаптирован для нейроотличных людей. Ночной режим — затемнённые мягкие тона, без активных звуков и викторин.
- **Аутентификация:** Не требуется. Все данные хранятся в LocalStorage.
- **ИИ:** OpenAI-совместимое API через переменные окружения (PROVIDER_API_KEY, PROVIDER_BASE_URL). Без ключей — мок-режим.
- **Ассеты:** Изображения бабушек и фонов загружаются из public/assets. Поддержка PNG и спрайт-листов.
- **Архитектура языков:** Конфигурационный файл с языками, бабушками, словарями. Добавление нового языка = новый конфиг без изменения логики.
- **PWA:** Service worker кэширует статику (CSS, JS, изображения) и данные (последние новости, словарь, профиль). Манифест содержит иконки 192x192 и 512x512, название приложения, тему оформления.
